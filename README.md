# Posh Pal - AI Productivity Suite for Resellers

Posh Pal is a premium, all-in-one productivity suite designed specifically for Poshmark resellers. It leverages AI to automate tedious tasks, helping sellers scale their business with minimal effort.

## Features

- **AI Listing Generator**: Upload a photo and get a professional Poshmark listing (Title, Description, Style Tags, and Hashtags) generated by Gemini AI.
- **Pricing Assistant**: AI-powered market analysis that suggests optimal price ranges based on brand tiers, category demand, and item condition.
- **Bundle Calculator**: Accurate profit calculator that handles Poshmark's complex fee structure (20% or flat $2.95).
- **Sharing Scheduler**: Automated closet sharing simulation to boost engagement and visibility.
- **Cross-Listing Export**: Format and export your listing data for eBay, Mercari, and Depop with one click.
- **Pro Subscription**: Monetized via Stripe, unlocking unlimited AI usage and advanced reseller tools.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository.
2. Install dependencies for both the frontend and the backend:
   ```bash
   # Install root dependencies (includes both React and Express requirements)
   npm install
   ```

### Running the Application

To run the full suite (Frontend + Backend), you need to start two processes:

#### 1. Start the Backend Server (Stripe Proxy)
The backend handles secure Stripe checkout sessions.
```bash
node server.js
```
The server will run on `http://localhost:3001` (or the port specified in `process.env.PORT`).

#### 2. Start the Frontend (Vite)
```bash
npm run dev
```
The app will typically be available at `http://localhost:5173`.

## Environment Variables

To transition from simulation to production, create a `.env` file in the root directory (and ensure your deployment environment has these set):

### Frontend (.env)
- `VITE_GEMINI_API_KEY`: Your Google Gemini API Key.
- `VITE_STRIPE_PUBLIC_KEY`: Your Stripe Publishable Key.
- `VITE_API_URL`: The URL of your running backend (defaults to `http://localhost:3001`).

### Backend (System Environment)
- `STRIPE_SECRET_KEY`: Your Stripe Secret Key.
- `PORT`: (Optional) Port for the Express server.

## Simulation & Mock Modes

The application is built with a "Simulation First" approach, allowing for UI/UX testing without active API keys.

- **AI Service**: If `VITE_GEMINI_API_KEY` is missing, the service falls back to `simulateAI`, returning a high-quality mock Patagonia listing.
- **Stripe Checkout**: If Stripe keys are missing or the backend is unreachable, the checkout flow will alert the user and simulate a successful redirect to `/?success=true` to demonstrate the "Pro" state transition.

## Handover Note

The application is currently in a **Production-Ready MVP** state. 

1.  **UI/UX**: The design system is fully implemented using Tailwind CSS with custom tokens defined in `tailwind.config.js` and `index.css`. It is fully responsive and mobile-optimized.
2.  **State Management**: Subscription status is managed in `App.jsx` and persisted via `localStorage`. For a multi-user production environment, this should be moved to a centralized database (e.g., Turso/SQLite) tied to a user authentication system.
3.  **APIs**: Both Gemini AI and Stripe are integrated. They are currently operating in **Mock Mode** for safety in the sandbox environment. Simply adding the environment variables listed above will activate the live services.
